# 9. NV⁻ end-to-end acceptance workflow

Source: locked plan point 9

## Scope

- Use C₃ᵥ and the four-bond N + 3×C model from `groupy/tutorial/7_NV_center.ipynb`.
- Build the representation, reduce it to `A1 ⊕ A1 ⊕ E`, and generate projected orbitals `a1'`, `a1`,
  `ex`, `ey`.
- Show exact coefficients as rendered LaTeX/Markdown and tables, with copyable Markdown/LaTeX.
- Run `ActiveSpace` for the four active electrons and show `³A2`, `³E`, `¹E`, and `¹A1` with spin,
  degeneracy, and provenance.
- Show determinant/configuration expansion only when a term is selected; keep the default result
  table readable.
- Render selected symmetry-adapted orbitals and connect them to the visual orbital objects.

This is the acceptance case for the whole plan.
