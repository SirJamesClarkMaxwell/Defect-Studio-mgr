# Task 113c — supercell convergence

Implemented the active case's supercell series in **Fonony: wykresy → Zbieżność**.

## Behaviour and click path

1. In **Fonony**, select a visible case and attach/import its phonon datasets at the desired supercell sizes.
2. Open **Fonony: wykresy → Zbieżność**. The largest parameter group is selected initially; **Seria** switches between groups.
3. Use **Skalar** to select S, DW, ℏω_eff or E_FC. The other three plots show S per irrep, PL and S(ℏω). The scalar selector keeps four readable plots in the existing window instead of adding four scalar panels. Irreps are lines, including `???`; the prescribed warning appears above 10% unknown S.
4. PL axis, normalisation and ZPL choices are shared with the PL tab. PL and spectral curves use a viridis-like gradient in member order; the bar labels the first, middle and last size. Right-click a legend entry for the existing style/visibility popup. Every plot has the existing export and figure controls.
5. **Eksport serii (Origin)… → Zapisz w exports/** writes one tab-separated `.dat` under the project's `exports/`. Existing files are preserved with `_2`, `_3`, … suffixes. The confirmation and completion path are project-relative.

Grouping uses exactly `(hr_method, hr_cutoff_A, sigma, sigma_max, gamma, source)`. All phonon members of the active visible case participate, independently of comparison checkboxes. Other cases and non-phonon datasets are excluded. FC-cell members with no supercell metadata come first, labelled **komórka FC**; their size is never guessed from atom count. The plot places them at zero with an explanation; the Origin n cell is empty. Recorded sizes use a for a=b and a*b*c otherwise, with the full AxBxC label.

S and DW come from the loaded summary. E_FC is Σ S_k ℏω_k for ω>0 and ℏω_eff is E_FC/S, independently of the comparison table's existing q-weighted RMS metric. Irrep sums use the same positive-frequency modes. Missing/invalid modes leave derived values empty, and S=0 leaves ℏω_eff empty. N_atoms is the loaded structure count. Summary-only fallback retains S/DW/spectra and reports the mode-read failure without inventing N_atoms or mode-derived values.

## Export and binding details

Read the reference `P:/PL-spectra/scripts/lineshape.py` in place; nothing on P: was written. Its actual scalar-key sort is **DW, E_FC, S, hw_eff**, followed by alphabetical `S_<irrep>` columns. The export follows that actual order, rather than the task's abbreviated S/DW/hw_eff/E_FC listing:

`E-E_ZPL, E, L_<AxBxC>… | hw, S(hw)_<AxBxC>… | n, N_atoms, DW, E_FC, S, hw_eff, S_<irrep>…`

Long Name / Units / Comments are produced by `SaveDataTable` with `originHeader=true`. Curve comments are `S=<value>` to three decimals, as in the reference. The first comment records method/cutoff/σ/σ_max/γ, the reference ZPL and source, and the grid rule. The relative-energy grid is the **first member's complete PL grid minus its selected ZPL, in meV**. Each member is sampled at its own ZPL plus that relative energy. `E` records the first member's absolute photon grid. S(hw) uses the first member's spectral grid. Linear interpolation and constant endpoints match `numpy.interp`; unavailable curves produce empty cells. Raw intensities are exported, independent of display normalisation, preserving the reference's `1/eV` and `1/meV` units. DataTableIO supplies ragged-column padding.

The filename is `PL_<method>[_cutoff<C>A]_sig<sigma>[-<sigma_max>]_gam<gamma>.dat` (legacy method metadata is labelled `legacy`). Saving stages the table in `exports/` and uses the existing `FileSystem::RenameNoReplace` to publish without an overwrite race. No new publish system, cache, spectra implementation, reader, job or dependency was added. References borrow the existing `PlotModes`/`Spectra` comparison cache and active loaded result. The export helper lives in a second `PhononPlotDataSeriesExport.cpp` to keep the adapter and export code small. No binding issue required stopping or changing another layer.
